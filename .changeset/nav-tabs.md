NavTabs: navigation drawn as tabs. A `nav` of `NavTabs.Link`s, plain links (or a router's, through `as`) with the current page's link marked by `active`, in every Tabs variant, color, size and orientation. Tabs now marks a disabled tab with `[data-disabled]` in its CSS instead of `:disabled`, which it already set.
